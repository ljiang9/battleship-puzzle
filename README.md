# battleship-puzzle 舰队谜题

终端里的 Battleships solitaire（舰队谜题/数舰）生成器与求解器：把一支舰队放进网格，
舰船之间互不接触（含对角线），每行/每列的船格数作为线索。纯标准库，零依赖。

## 玩法

- 棋盘 `n×n`（6 / 8 / 10），舰队：
  - 10×10：1×4、2×3、3×2、4×1（共 20 格）
  - 8×8：1×3、2×2、3×1（共 10 格）
  - 6×6：1×3、1×2、2×1（共 7 格）
- `#` = 已知船格，`~` = 已知水格，`.` = 未知；上方/左侧数字是该列/行的船格数。
- 求解器用回溯 + MRV + 行列剪枝 + 预设船格覆盖分支。

## 用法

```bash
python3 -m battleship_puzzle                 # 生成一道 8x8 谜题
python3 -m battleship_puzzle --size 10 --seed 7
python3 -m battleship_puzzle --size 6 --solve # 生成并求解
python3 -m battleship_puzzle --save p.txt      # 存档
python3 -m battleship_puzzle --load p.txt --solve  # 读档求解
python3 -m battleship_puzzle --solution       # 生成时直接附答案
```

谜题文本格式：第 1 行是尺寸，第 2/3 行是行/列计数，之后 n 行用 `#`/`~`/`.` 表示格子。

## 真实验证

- `python3 -m py_compile battleship_puzzle.py __main__.py` 通过。
- 手工验算的 6×6 谜题（3+2+1+1 舰队，行 `[3,0,1,1,1,1]` 列 `[1,2,3,0,0,1]`）：
  求解器找回了唯一真布局，`check_solution` 判定合法。
- 生成谜题可解性：6×6 与 8×8 各 20 个种子（0–19）**全部**在 0.05 秒内求出合法解；
  校验覆盖船队组成、无接触规则、行列计数、预设格一致。
- 10×10 抽查：约束充足的实例可瞬间求解；预设过少的实例可能超出默认搜索节点上限。

## 已知局限（诚实版）

- 求解器是回溯搜索，不是多项式算法：**10×10 且预设很少**的谜题可能搜不出解
  （默认 `--max-nodes 2000000`，可调大；此时程序如实报告"求解失败"而不是假装有解）。
- 生成的谜题**不保证唯一解**：只要布局合法、计数相符，任何解都被接受。
- 生成器只保证"有解"（拿随机合法布局当答案反推谜题），不做难度分级。
- 需要 Python 3.10+；中文界面。

## 构建时修过的 bug

1. `place()` 把同一条船尚未放置的相邻格也标成了水——多格船永远放不全，手算 6×6 直接无解。修复：标水时跳过本船格子。
2. 10×10 回溯在小约束实例上打转：加了"预设船格覆盖分支"（优先分支必须覆盖的预设格），seed 0 从 22 秒降到 0.0 秒。
